# EAB — Site vitrine

Première version du site cinématique EAB.

- Site statique : `index.html`, aucun build nécessaire.
- Animations de défilement, cinq écrans, fond animé, navigation et version mobile.
- Déploiement automatique par Vercel quand le dépôt `augustinteman/eab-site` est correctement lié au projet.
- Visuel produit attendu : `assets/fauteuil.png` (image de référence EAB) à ajouter dans le dépôt GitHub.
- Remplacer l'adresse `contact@example.com` par l'adresse officielle du client avant publication.
- La rotation complète à 360° nécessite un modèle 3D authentique du fauteuil ; cette première version utilise seulement une légère animation 2D pour éviter de fabriquer des vues inconnues.
